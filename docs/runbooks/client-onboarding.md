# Client Onboarding — HM Digital + CEZIH (smart card setup)

Everything a new clinic (tenant) and each doctor need, from bare Windows to a
working CEZIH connection. Written 2026-09-07 from the official CEZIH/HZZO/AKD
sources; verify links occasionally — CEZIH reorganizes rarely but does.

Official sources:
- VPN client + card utilities: http://www.cezih.hr (sections "VPN klijent", "aplikacije")
- Vendor walk-through of the card + VPN flow (Eskulap): https://edborel.hr/content/upute/eskulapwin/vpn-konekcija.html
- HZZO FAQ (e-zdravstveno, root certificate): https://hzzo.hr/poslovni-subjekti/e-zdravstveno/pitanja-i-odgovori

NOTE: www.cezih.hr serves a self-signed certificate chain — browsers will
warn on download pages. This is their known quirk; proceed (add exception)
on the official domain.

## 1. Per-clinic (tenant) prerequisites — collected before setup day

| Item | Source | Where it goes |
|---|---|---|
| Šifra ustanove (HZZO) | Client already has / requests from HZZO | Postavke > Organizacija |
| Info-system OID | Auto-generated by our app (TC6) | Postavke > Organizacija → "Generiraj OID" |
| Tenant + user accounts | We create in the admin | — |
| USB smart card reader (ISO 7816) per workstation | Client buys (any CCID reader; Windows 10/11 auto-installs) | — |
| AKD pametna kartica per doctor | Ordered via FINA / already held | Card arrives activated with PIN letter |

Doctors choosing **Certilia (extsigner)** signing still need the card: the
VPN authenticates with the card certificate regardless of signing method.

## 2. Workstation software install (per doctor PC, ~15 min)

Order matters: card software BEFORE the certificate step.

1. **Certilia Middleware** (REQUIRED — our cards are Certilia-issued; this is
   what makes Windows claim the card and import its certificate)
   - Download: https://www.certilia.com/preuzimanja →
     `Certilia_Middleware_v3.9.10.exe` (Win 10/11 x64; MSI 3.9.9 available
     for enterprise deployment)
   - After install, insert the card — Windows auto-imports the certificate.
     If it doesn't: Certilia's support article "uvoz certifikata s kartice
     nije uspio – Windows" (same page).
   - The same page also hosts CA root certificates (AKDCA, KIDCA, Certilia)
     if chain validation is ever needed.
   - ⚠️ Do NOT confuse with the AKD "akdSHCard" utility on cezih.hr — that is
     for the HZZO osigurane-osobe "smartica", a different card family; it is
     useless for our cards (verified the hard way 2026-09-07).
2. **Cisco AnyConnect (Secure Mobility Client)**
   - Official CEZIH build: http://www.cezih.hr/VPN_klijent.html
     (direct MSI: `infog2/anyconnect-win-4.10.07065-core-vpn-predeploy-k9.msi`,
     Windows 10/11)
   - Same page: **HZZO CA root certificate** (`certifikat/hzzo-cert.der`)
     — install once per machine (Open → Install certificate → Next →
     Next → Finish) or certificate chain validation fails later.
   - Install with the default Core VPN feature set only.
3. **HM Digital Agent**
   - Public download (no login): https://github.com/disjohndoe/agent/releases
   - Auto-updates itself within 30 min of every release — one-time install.

## 3. Card certificate (per doctor)

1. Install Certilia Middleware first (section 2.1), then insert the card.
2. Windows automatically imports the card certificate into the user store —
   verify in `certmgr.msc` > Personal (a certificate with "Certilia"/AKD
   subject, private key on the smart card).
3. If the import didn't happen, follow Certilia's "uvoz certifikata s
   kartice nije uspio – Windows" article.

## 4. VPN connection (AnyConnect)

1. Server address:
   - **Production: `pvpri.cezih.hr`**
   - Test (our internal testing only): `pvsek.cezih.hr`
2. Connect → certificate is auto-selected from the card → enter card PIN
   (once per session; the session idles out after ~30 min).
3. Recommended client settings (Eskulap guide): automatic certificate
   selection ON, "allow local LAN" ON, "do not remember PIN" OFF.
   If the settings don't appear, connect once and disconnect — they show up
   after the first attempt.

## 5. HM Digital app setup (tenant admin, in the web app)

1. Log in at https://app.hmdigital.hr (credentials we provide).
2. Postavke > Organizacija: enter **šifra ustanove**, click
   **"Generiraj OID"** (requires agent + VPN + card from steps 2–4).
3. Postavke > Korisnici (per doctor):
   - Set **način potpisa**: AKD kartica or Certilia mobilni.
   - For Certilia users: enter the doctor's **OIB** (auto-fills when the
     card is bound; otherwise an admin enters it manually — 11 digits).
4. Pair the agent: the CEZIH page generates the pairing link
   (`hm-agent://…`) — click it with the agent running. Released agents
   default to `wss://app.hmdigital.hr` — clients never type a URL.
5. **Poveži karticu** (bind card) — links the doctor to their card holder
   name and fills the OIB.

## 6. Verification checklist (go-live acceptance)

- [ ] Agent status window: Cloud / VPN / Kartica all green

## 7. Known issues & notes (2026-09-07)

- Agent versions **< 0.13.2** flash black console windows while the VPN is
  disconnected (fixed in 0.13.2; clients auto-update).
- cezih.hr self-signed browser warnings — expected, proceed on the official
  domain.
- One PIN entry per VPN session; card stays in the reader while working.
- Certilia cloud certificate ≠ VPN certificate: Certilia handles signing
  only; the VPN always uses the AKD card certificate.

## 8. Automation status / roadmap

- Automated today: agent install + auto-update, agent pairing, OID
  generation, OIB auto-fill on card bind.
- Recommended next: agent "Provjera postave" preflight — detect reader /
  card certificate / AnyConnect / VPN and deep-link the official downloads
  for anything missing (turns this runbook into a wizard; PIN steps stay
  manual by design).
- Not automatable: PIN entries, certificate registration (credential
  operations must be user-driven).
